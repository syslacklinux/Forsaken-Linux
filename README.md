# Forsaken Linux — The Isoless Distribution Beyond Time

Welcome to Forsaken Linux, the Isoless Debian‑based Linux Distribution!  
No ISO Needed — Forsaken Linux is born from Debian, transformed by post‑install scripts, branding, and philosophy.
📖 Origins & Resilience

    Forsaken Linux 1 Eclipse — released July 17, 2026, based on Debian 11 Bullseye, kernel 5.10. First version, multi‑architecture support.

    Defeat is not the end — Forsaken Linux was discontinued August 31, 2026, but returned September 12, 2026, stronger than before.

    Forsaken Linux 2 Stalemate — released September 13, 2026, based on Debian 12 Bookworm, kernel 6.1. Introduced GNOME 43, KDE Plasma 5.27, switched from doas to sudo, streamlined architectures (dropping mips).

🚀 Roadmap of Releases

    Forsaken Linux 3 — based on Debian 13 Trixie, adds riscv64 support, kernel from trixie‑backports.

    Forsaken Linux 4 — based on Debian 14 Forky, kernel from Debian 14.

    Forsaken Linux 5 — based on Debian 15 Duke, kernel from Debian 15.

🔧 Hardware Enablement (HWE)

    HWE 1 — released September 13, 2026, based on Trixie backports.

        Kernel 6.5 backport.

        Mesa 23.x graphics stack.

        Updated firmware packages.

        Improved virtualization drivers.

        Experimental riscv64 support.

    HWE 2 — planned, based on Forky backports.

🎨 Identity & Branding Features

    Custom /etc/os-release branding with Forsaken Linux name, codename, and logo.

    Forsaken logo integrated into /usr/share/pixmaps.

    GRUB distributor string set to “Forsaken.”

    /etc/dpkg/origins/forsaken vendor registration.

    Fortune + bsdgames for login personality.

    /etc/issue customized to welcome users with Forsaken’s identity.

🌐 Philosophy

    Isoless — Forsaken Linux does not ship ISO images; it is installed by transforming Debian into Forsaken through scripts and branding.

    Resilience — Forsaken Linux rises again after discontinuation, symbolizing persistence.

    Evolution — Each release aligns with Debian’s lifecycle but adds Forsaken’s unique identity and enablement stacks.
